常見問題

沒有中文語音，還能玩嗎？

可以。所有操作都有圖文提示。先確認沒有靜音；原生 App 只使用已安裝的合適本機音色，沒有音色也能繼續玩，不會自動下載。家長可自行在裝置語音設定查看可用音色。

畫面卡頓或裝置發熱

在家長設定選擇低畫質，關閉其他高負載 App，再重新進入遊戲。回報時請附裝置型號、系統版本與模式，方便維護者重現。

手機方向盤無法啟用

使用觸控轉向即可完成汽車遊戲。傾斜轉向需要相容的動作感測功能及家長啟用；瀏覽器版還需要安全連線與瀏覽器權限。

飛機、火車的操作可以再練習嗎？

可以暫停、重玩或返回大廳。飛機的返航使用持續的助飛控制；火車「幫我停好」透過列車動力與煞車慢慢停靠，不會直接移動到終點。

怎麼清除設定與遊玩紀錄？

使用裝置的 App 儲存空間設定清除資料，或刪除 App。系統備份可能在重新安裝時還原設定；備份由裝置平台管理。瀏覽器版可清除這個網站的資料。

可以離線玩嗎？

原生 App 的遊戲模型、圖片、字型與程式隨安裝提供。瀏覽器版第一次需要網路載入；完成離線快取後可再使用。外部支援頁與 GitHub 問題追蹤需要網路。

Support — English

Public support and privacy email: a820628a@gmail.com. Parents can use that address in their own mail app; the native game only displays it. Parents can also contact the maintainers through the project's public GitHub issue tracker. The game itself does not require an account. GitHub uses its own account system for posting issues.

Include the device model, operating system, app version, game mode, and steps to reproduce. Do not post a child's name, photo, date of birth, passwords, or other private information. In the native app, use the displayed address in a separate browser; the app does not open external sites. In the browser version, the parent button opens support after a parent challenge.

Missing local voice data does not prevent play: full on-screen guidance remains available. Lower the graphics setting for less powerful devices. Touch steering works without motion sensors. Native game assets are bundled for offline use; external support requires an internet connection.

The interface and spoken guidance are in Traditional Chinese. These English support and privacy summaries do not imply a fully translated English game interface.
