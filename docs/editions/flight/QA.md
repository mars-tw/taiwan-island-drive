# 可執行驗證

2026-10-05，Node.js 24、Three.js 0.186.1、Vite 8.3.2。

- `npm test`：24 項通過。
- `npm run build`：完成正式版，precache 收集 24 個同站檔案，含 GLB、IMG、字體與 PWA 圖示。
- `node --check src/main.js`、`game.js`、`world.js`：通過語法檢查。
- `scripts/package-source.ps1`：產出完整開源 ZIP；確認真實 `.blend`、GLB、dist 及第三方授權存在。

物理測試涵蓋 SI 換算、無效步長、重力、漸進加速、迎角失速、襟翼升力、輪胎煞車、風速與地速差、傾斜轉彎、長步長數值穩定，以及 Three.js 駕駛相機投影：右副翼、右方向舵與地面鼻輪轉向都向畫面右方；正俯仰抬頭，正滾轉降低駕駛右側機翼。兩組機型參數均從地面加速起飛到課程完成，再由進場完整接地並煞停；另以物理飛行穿過三個導航圈。

幼兒模式直接呼叫遊戲同一個 `FlightGame.prototype.childControl` 與 `input`，驗證大按鈕引導的起飛、導航、降落都能完成。測試不直接改位置或速度跳過任務。

手機實際介面、座艙視野、觸控與離線瀏覽器驗證由最終整合驗收記錄補充；這份紀錄不把程式測試當作實機證明。合成語音依瀏覽器可用語音，沒有語音時同樣顯示完整字幕。

起飛課驗收補強：記錄首次與最近一次離地的跑道接觸，以及實際拉桿抬頭操作。只推油門、不按抬頭，不能因低高度自然浮起而取得課程完成；接近跑道末端就提示重試。草地離地不給起飛課學分，自由模式仍可在草地起降。四項回歸測試與既有三課通關測試均通過。

幼兒提示驗證：只有油門時，翼型可能先自然浮起不足一公尺；介面仍依 rotationCommanded 提示「抬頭起飛」，不依 grounded 提前改成保持平穩。回歸測試自然浮起後按抬頭，以實際控制力矩完成課程，未直接改位置或速度。
