- `npm test`：13 項測試，涵蓋門／電源／方向互鎖、慣性惰行、制動延遲、緊急與常用煞車比較、坡度與停車距離、無效 dt、紅燈等待、越紅燈保護與恢復、停站流程、超站先停穩再倒車恢復，以及三路線 × 三課程連續物理駕駛。
- 超過課程終點 100 公尺的保護修正：前向行駛或請求前向牽引會觸發緊急煞車；停穩解除後，可以實際低速倒車回到 420 公尺停車區。新增測試確認不瞬移、不反覆觸發保護，倒車速度低於 3 m/s，停車誤差符合前後 12 公尺。
- 三路線 × 三課程的停車協助實際完成所有上下客和關門程序；每個 1/60 秒位置變化少於 0.3 公尺，沒有傳送到站或直接設定速度。測試停車誤差約 0.8～3.2 公尺。
- Blender train.glb 4.23 MB、train-cab.glb 3.14 MB，兩者內嵌真正 IMG atlas。瀏覽器回報模型載入 `ready`，WebGL 渲染可見車窗、操作台、左右控制桿與即時 3D 儀表。
- Chromium 桌機 1280×720、直向手機 390×844 的 UI 截圖，主操作無水平溢出，模型可見。六個幼兒主要按鈕實際為 114×87 px，文件寬度等於視窗寬度 390 px。以真實 UI 點擊準備、前進和停車協助，回讀速度 11.24 km/h，協助停車誤差 1.43 公尺，可開門上下客；瀏覽器主控台 0 個錯誤。
- UI 點擊開門、完成 4 秒上下客、再點擊關門，第一課實際顯示課程完成視窗與 98 分，停車誤差 1.44 公尺。畫面保留 `docs/lesson-complete.png`。
- PWA precache 使用 `train-school-` 獨立快取名稱，所有 URL 相對於網站 scope；不刪除其他遊戲快取。完整 build 會包括模型、PNG、字型與第三方授權聲明。
- 本機正式 build 在 localhost:5182 驗證，Service Worker 控制頁面且 `train-school-v1` 存在。設為網路離線後重新載入，兩個模型仍回報 `ready`，`navigator.onLine=false`，遊戲與字型成功顯示。

語音以裝置 `speechSynthesis` 實作。自動化瀏覽器只能驗證呼叫與文字顯示，聽感及真實 iOS／Android 的中文音色仍受裝置語音包影響。
