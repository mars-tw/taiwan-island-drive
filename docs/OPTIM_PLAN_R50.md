# 島嶼交通學院 R50 計畫：中英文切換

使用者指示（2026-11-24）：「島嶼遊戲也要有中英文版切換的功能」。

## 現況（2026-11-24 盤點）
- 全站沒有任何多語系機制。`index.html`、`car/`、`train/`、`flight/` 都寫死 `lang="zh-Hant"`，玩家看得到的字直接寫在程式裡。
- 字量：112 個 js 檔含中文，不重複的中文字串約 2,500 條（約 2.2 萬字），四個 html 另有約 2,200 字。
- 字量分布：數學遊戲室約 1,040 條、飛機約 230、火車謎題約 180、`content-r1-ui.js` 約 160、火車約 150、汽車約 100，其餘散在 `content-r*-scene.js`、`academy-ui.js`、`safety-ui.js`、`journeys.js` 等。
- 語音一律 `speakNative(text, { lang: 'zh-TW' })`，在 `src/shared/native.js`、`train/main.js`、`flight/voice.js`、`math/room-ui.js` 等。
- 圖片裡烘進去的中文字（站牌等）要另外盤點。

## 設計原則
- 預設語言：第一次開啟時，裝置語言是英文就用英文，其他一律繁體中文；之後記住玩家的選擇。
- 切換入口：首頁頂端放一顆「中文／English」切換鈕（≥60px），家長設定裡也放一份。切換後當頁立刻換字，不清掉進度。
- 中文版的字一個都不變，現有測試照舊要過。
- 英文版：給 3～8 歲的簡單英文、句子短，專有名詞（站名、地名）用官方英文拼法。全站用同一份用語表 `docs/i18n/GLOSSARY.md`。
- 語音跟著語言切換（`en-US`／`zh-TW`），沒有英文語音的裝置要安靜退回，不能報錯。
- 數字、時間、日期照語言格式化。
- 英文通常比中文長，三種尺寸（390×844、844×390、1366×768）都不能擠壞、切字、重疊，按鈕仍 ≥60px。

## 分線
- **L1 核心＋共用**：寫 i18n 模組（`t()`、帶參數的句子、語言偵測與記憶、切換事件、`<html lang>`、語音語言、數字格式），做切換鈕。翻好首頁、學院外框、家長設定、安全提示、四個 html，以及共用的 `academy-ui.js`、`safety-ui.js`、`parent-gate.js` 等。訂用語表，並加「英文字典沒有漏翻」的守門測試。**先做**，其他線用它的 API。
- **L2 數學遊戲室＋火車謎題**：`src/games/math/`、`src/games/puzzles/`、`data/*.json` 的玩家文字、題目語音。等 R49（圖示）併入 main 後才開工，避免衝突。
- **L3 三種駕駛課**：`car/`、`train/`、`flight/` 與 `content-r*-scene.js`、`content-r*.js`、`journeys.js` 等場景文字和語音。字量大的話，L3 再拆成汽車＋火車、飛機＋其餘場景兩條。
- 每條線都要：中文模式結果和改前完全一樣（字串比對與既有測試）；英文模式三種尺寸截圖；漏翻檢查為 0。

## 驗收
- `npm test` 全過（含新守門：每個 `t()` 用到的字都有英文；中文原文不變）、`npm run build` 過。
- 英文模式下跑過首頁、遊戲室四個分頁、三種駕駛課各一關，三種尺寸截圖放 `docs/evidence/r50/`，頁面錯誤 0。
- 獨立評審：Claude 與 MUSE 各看一次英文版截圖（英文是否自然、小朋友看得懂、版面）。
- 版本 2.51.0（R49 圖示輪用 2.50.0），本機提交，推送前先問使用者。
