## 三個製圖工具分工
- gpt-image-2（專案指定主力）：OpenAI `/v1/images/generations`，模型 `gpt-image-2`。
- Grok Build 的 Imagine（`image_gen`／`image_edit`）：第二來源，或修圖。
- MUSE：開工前訂風格，候選出來後看總覽圖挑選、指出要重畫的。
- manifest 每張寫實際工具與模型 slug；工具沒揭露的就寫 null 並註明，不寫 latest。

## 八大面向對照（本輪範圍）
1. 美術：本輪主體。圖示統一圓潤繪本貼紙、墨藍粗框、學院色票；64px 可辨。
2. 按鈕：卡片、分頁、喇叭、轉轍器按鈕維持 ≥ 60px、在畫面內、不重疊（新測試＋截圖量測）。
3. 選單：遊戲室分頁與卡片結構不變，只換圖示；橫式 6 張卡守住。
4. 人物：本輪不新增人物；圖示裡的乘客只是小配角。
5. 地圖模型：轉轍器的列車換成俯視圖，跟俯視軌道同一個視角。
6. 技能：不適用（沒有技能系統）。
7. 腳色樣子：不新增角色；圖示做灰階與 64px 檢查。
8. 動作流暢度：列車沿軌道移動的程式不變，只換圖。

## 品質閘門
- `npm test`、`npm run build` 全過；秘密掃描零命中。
- 三種尺寸截圖與量測 JSON 入 `docs/evidence/r49/`。
- 不改版本號（主控改 2.50.0）、不推送、不改 `.github/workflows`、不動 android／ios 原生資料夾。
- 效能：本輪只換靜態小圖與 CSS，不動遊戲迴圈；p95 由主控整合後統一量。
