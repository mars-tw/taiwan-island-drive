三課都在**首頁 → 海岸實作課 → 選課 → 一起出發**。採2D海岸互動場景、持續輸入控制與同一份學生存檔；每課有三站，可隨時休息、回學院或重玩。每站完成即保存，關閉途中一站會回到該站起點；已完成紀錄不因重玩消失。
