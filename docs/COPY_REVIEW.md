## 公開版本更新

原句：「目前交付的是本機開源專案與下載包，尚未建立公開 GitHub 儲存庫。」原因：使用者已要求公開，且 GitHub 與 HTTPS 部署已完成。改成：公開專案與遊玩網址，另保留尚未上架 App Store／Google Play 的事實。

新增手機加入主畫面與自動部署說明，內容對應實際 PWA 設定和通過的 GitHub Actions 流程。

## 2026 年 10 月 6 日合併更新

原句：「同系列還有島嶼鐵道學校與島嶼飛行學校。」原因：三套程式已實際整合，原文會讓人以為仍是三個獨立開發專案。改成：「汽車、火車與飛機已合併成同一個開源手機遊戲專案。」

保留 3～5 歲定位、手機方向盤的正常權限提示、IMG UV 貼圖、原始模型、MIT／OFL 授權及瀏覽器模擬的驗收限制。沒有把遷移後的模型或程式重複稱為新生成。

原句：「public/textures 保留兩張 ImageGen PNG atlas。」原因：2.1 版已真正產生三張 16 格材質板，並完成逐面 UV 對位。改成：說明三張新 IMG、48 個材質格與兩張歷史 atlas，附模型與 UV 驗證文件。
