# 島嶼交通學院：山海同行

2026-10-16；2.7.0；EXECUTED。維持同一款《島嶼交通學院》更新，不建立新 App。

## 一個學院，一趟任務

玩家是島嶼交通學院的新學員。海風站的朋友要去山海教室，教練交給玩家一份調度單：先分好乘客，再接客、送補給，最後從空中找路標。沒有敵人、倒數、付費、登入或失敗扣分。

| 章節 | 真正操作 | 前章如何影響後章 |
|---|---|---|
| 1 列車數學課 | 同一班乘客逐人裝滿、可逆分車、用減法確認前車帶走幾人 | 正確完成才開主線接客；實際前車人數寫入交接調度單；共用火車星星＋1 |
| 2 海風站接朋友 | 原火車物理：準備、起步、煞停、開門等乘客、關門 | 用數學調度人數標記本趟任務；完成 train-1 才能從主線繼續公路補給 |
| 3 公路送補給 | 原汽車 360m 海岸短程：油門、煞車、轉向與找星星 | 完成 car-1 才繼續空中找路標 |
| 4 空中找路標 | 原飛機助飛、找兩顆路標星星，沿用真正飛行物理 | 完成 flight-1 取得山海同行章，回學院可重練與看學生證 |

每章仍在同一個世界、同一張學生證。主線按鈕只有一個「接下／繼續」入口，結果頁直接交給下一章，不是四個互不相干遊戲的選單。原三交通工具自由玩法、12 關護照與安全觀察課繼續作為學院練習；既有玩家不被新鎖擋住。已完成的舊第一關可算作對應章節，無須重刷；數學調度仍需完成或由家長匯入。主線進度依連續完成順序計算，不拿未解鎖章節冒充當前任務。

首頁首屏顯示第一章，按一次即開真實數學操作教學，再按開始即可逐人上車。小螢幕隱藏較長任務說明時，數學開場仍直接交代海風站與山海教室。自動操作的冷啟動、第一玩法與第二模式用時記在 `evidence/merge/merge-path.json`；目標是 3 分鐘／10 分鐘可達，不把自動化用時當作幼兒理解或 beta 證據。

## 學生證與保存

唯一 canonical 進度鍵為 `island-transport:student:v2`，內有數學班次／活動階段／人數、交接單、三種交通星星、12 關最佳評等、安全觀察站數、共用設定與選擇匯入的歷史原文。收集貨幣仍只有星星；評等與徽章是成就，不另造可消費貨幣。數學完成只發一次星星，錯答、重載完成頁、匯入都不免費發星。

升級時先讀 v2；沒有時讀原 rewards／passport／safety／settings、汽車 preferences／records、飛機成績及大廳音樂共八個舊鍵，第一次寫入以完整快照存 v2。原鍵不刪除，只在其對應部分更新時保留向後相容快照；現在所有玩法、車種／選色、個別最佳成績與音樂開關都讀 v2，這些鏡像不是八套互相競爭的存檔。localStorage 寫入本身為單鍵原子操作；失敗時保留 session、明示未保存。無雲端同步。

原生使用同一份 v2 record 同步到 Capacitor Preferences 作恢復副本；已有本機 v2 時不讓較舊 Preferences 覆蓋。來源層與打包測試不代表已驗原生 App 的程序終止／還原。

## 舊數學遊戲匯入

家長設定必須先通過既有家長關卡，再選本機 JSON。支援來源 `taiwan-train-math.backup` version 1／passport version 1（包括 1.13、1.14 所用格式）；沒有 dispatch 的舊備份也可保留歷史。上限 256 KiB，錯誤格式、非法數量／階段不更動現有進度；重新匯入採最大完成班次，不重發星或推翻現有完成章。若新備份將覆蓋目前未完成的一班，拒絕並要求先完成當班。

可接續的是來源 dispatch 數學教材。原圖鑑、照片、拼圖、禮物、旅程與 session 原文隨備份完整留在學生證的 archive；本版沒有移植那些玩法，不能繼續其當次拼圖／旅程，也不把它們兌成學院未完成的章。請家長保留來源備份及原 App；不同 Bundle ID／網站 origin 無法直接讀對方沙盒，不自動偵測或刪來源。現有來源 repo 與其未提交文案全程唯讀。

## 外觀、無障礙與暫停

數學純模型移植在 `src/games/math/dispatch.js`；介面由 `academy-ui.js` 接入共用大廳，無 iframe、第二套設定、登入、貨幣或獨立載入器。用學院紙色／青綠／金色、系統繁中字型與既有 WebAudio 慶祝聲。雙車廂與乘客圓點為可存取 DOM 教材，不是假 3D 人物、沒有用單張圖片晃動冒充角色動畫。原有 3D 車輛、風景、物理與聲音回歸。

兒童主線、數學、返回／暫停與學生證命中區至少 60×60 CSS px。暫停有繼續／返回，失焦、背景、原生 back 依共用生命週期處理；數學每個動作存檔，關閉後回原階段。採 reduced-motion，沒有壓力倒數。家長頁可捲動；兒童操作列維持可見。

Web 沿用同一 Service Worker 預存；原生沿用同一 Capacitor 本機 payload。所有新程式、教材與授權隨包，遊玩不讀遠端 URL。不新增廣告、分析、購買或評分 SDK。家長區只是本機備份讀取，沒有對外連結。

## 保留與取捨

保留來源最完整的數量守恆玩法與 36 班／三種難度迴圈測試，刪除的是移植範圍內重複外殼需求：不帶入原首頁、圖鑑、另一套家長關卡與設定頁。來源檔案本身不刪改。兒童模式使用小數量，家長切完整模式後用中數量；來源大數量模型與測試保留，本版 UI 未獨立提供大數量選單。

沒有內嵌過渡技術債。尚需後續產品工作：更多互相影響的手工故事章、真正乘客角色動畫、來源其他玩法是否值得以課程移植的決策。原生簽章／真機、兒童試玩、閒置機器效能與既有音樂權利是出貨缺口，不以本次整合掩蓋。
