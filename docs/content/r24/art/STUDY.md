# R24 美術研究與落地

PREPARED，2026-10-20。讀取 [GCompris 官方畫面與操作](https://www.gcompris.net/screenshots-en.html) 及 [SuperTuxKart Style](https://supertuxkart.net/Style)。前者用圖像選擇與固定工具列支持兒童辨識；後者的卡通世界以明確造型及一致場景支撐可讀性。以下為本作設計推論，不複製其素材。

應用：保留固定海藍交通控制，三站差異以榕樹根／紅瓦候車亭、近景燈塔／岩岸與漁港區分；不以換色或左右鏡像代替換景。路口橫向道路置於畫面38%至64%，垂直斑馬線穿過兩車道；車與人路徑同源。車站保留同一軌道高度及列車尺度，實體站牌與月台鋪面連接。輪廓、左上暖光及六色色票沿用 ART_DIRECTION 與 R20 PROMPTS 完整前綴。生成後做原尺寸、64px與接線檢視，僅轉碼，不程序繪製插畫。

工具使用雲端內建 `image_gen.imagegen`；不呼叫本機GPU。工具若未揭露model slug，記null，不猜測。新增背景無人物，角色沿用現有受管多姿勢原畫，沒有新增骨架或3D物理。
