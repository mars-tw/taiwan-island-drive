# R33美術技法對照

生成前讀取本MIT遊戲的 `docs/art/ART_DIRECTION.md`、R32完整PROMPTS與既有乘客／灣位／道路原畫；本紀錄在整合後整理，未聲稱另做網路研究。

沿用海藍、橘、黃交通繪本、深藍輪廓與紙面筆觸。角色比例保持大頭、可讀臉部、同服裝背包與鞋色；三人不是新身份。站穩圖採雙腳共地面基準，坐姿雙膝屈曲、臀部對座墊，取代跨步圖被當成已坐下。原雙步態仍負責走路，站／坐姿不冒充完整骨架循環。

灣位與主路畫在同一幅連續原畫，使用相同地面、光源與遠景消失線，取景移動不再疊兩張背景。右側格位、中央無路緣出口、左側主路留出連續行車區；P牌只在灣位範圍。主車進入右側車道，停止標記採交通資訊層並避開角色。

原圖與執行素材均留存SHA；Sharp只裁格、alpha裁邊、等比縮圖與WebP轉碼。七張色彩閘門通過；64px辨識沿用三位乘客的橘衣、紅裙與帆船帽剪影。只改2D姿勢與場景，不改3D模型，未新增戰鬥技能或傷害流程。
