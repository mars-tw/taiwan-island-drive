# R21 踏階：本作MIT繪本素材比較

EXECUTED。研究來源為本開源遊戲既有 `public/art/content-r10/boarding-step.png`、R20手機上車原圖與 `docs/art/ART_DIRECTION.md`。沒有引入外部遊戲素材或授權不明圖像。

既有圖在手機約70×22px，階面與列車同為海藍色，細黃邊容易混進車底。新圖保留圓角、墨藍輪廓及藍色防滑面，把黃黑安全條集中在前緣，讓「伸出物件」的剪影可單獨辨識。階面在390px手機顯示約87×46px，下方短標「踏階」；收回時圖和標籤一起完全隱藏。64px檢視另存 `boarding-step-64.png`。

實際工具 `image_gen.imagegen`，一次編修、一個設計、一個runtime WebP。工具未揭露模型slug，記null，不假填gpt-image版本。Sharp只做alpha裁邊、WebP編碼與64px檢視，沒有程序繪製美術，也沒有使用本機GPU產圖。

美術角色、背景和列車沿用受管原圖；人物沿用既有姿勢，不宣稱新增骨架動畫。階面伸縮是2D物件狀態演出。真人三秒盲看仍需參與者，不把執行者看圖或像素差當作通過盲測。
