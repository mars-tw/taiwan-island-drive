# R12 月台空間修整

PREPARED → EXECUTED。參照本 repo 受 MIT 管理的 R3 列車側視原畫、R10 月台及 ART_DIRECTION；此次是既有2D場景的幾何銜接修正，無新增人物、3D模型或外部素材。

既有畫面：門檻與月台邊同高，但高擋土牆使小列車的車輪懸在鐵軌上方。保持列車原比例、亮黃門框與深色車內；將既有月台重畫為低月台，後軌靠近黃邊，讓門檻、踏階與輪軌接觸同時可辨。深藍輪廓、三主色、左上暖光與留白控制區沿用 R11 PROMPTS 前綴。只透過 image_gen.imagegen 編輯場景，Sharp 僅編碼 WebP；未用程式畫背景。

透明角色與車輛全部重用。開門加深色內部、黃色框，安全斜紋屬交通提示。踏階維持水平，人物腳底只接觸階面上緣，踏階右側保留可見區；門口人物高度小於車身60%，不高過車頂。

實際工具與完整提示在 PROMPTS.json，原圖及執行檔 SHA 在 manifest.json。工具未揭露模型 slug，照實記 null，未冒稱特定模型。新圖為1024×1536；不計入新玩法。
