# R9 步態與落腳面研究

PREPARED／EXECUTED，2026-10-19。本輪直接研究本款 MIT 開源實作與受管素材：src/shared/content-r7-scene.js、content-r3-scene.js、public/art/content-r7/grandma-0.png／grandma-1.png、docs/art/ART_DIRECTION.md。沒有新增外部素材或授權。

原兩張奶奶分別為長跨步與抬膝；原精選只差很短時間，中心位移不足。採動畫 contact／passing／contact 的剪影原則，在行程 0～34%、34～72%、72～100% 分配跨步、抬膝、落腳，攝影取樣在起步緣、中線、抵達緣，保留接觸陰影與相同腳底基準。第三張由 image_gen.imagegen 依同一角色參考產生；工具不回傳 model slug，manifest 不推測模型名。

原車票上客有三條同時收斂至同一門口的路徑，故即使總人數正確仍會疊身。本輪改為前一位完成進車廂才讓下一位動身，月台腳底統一在背景橘色鋪面，站牌移到天空操作帶，軌道保留在車輪下。車廂內有可見的門口→走道→座位位移，受控狀態與座位數分開核對。

角色圖延續 420×400 alpha 畫布、350px 身高、25px 腳底留白。保留海藍／橘／黃、粗墨藍輪廓、上左暖光；不以新幾何或 emoji 代替角色。最終 64px、亮度與飽和度讀值及原尺寸手機證據在 manifest／驗證報告。

VERIFIED：已以原尺寸開啟 grandma-2-64.png，64px 下可辨灰色髮髻、綠外套、黃裙與藍色菜籃車，落腳腿與後抬鞋的剪影分開。非透明像素平均亮度約 0.507、HSV 飽和度 0.622、近黑 20.54%、低飽和 18.98%；通過既有 0.30～0.75、≥0.32、<35%、<20% 閘門。
