# 繁中文案 mode 2 事後紀錄

依核心規則常駐 mode 2 直接套用。本輪文字為兒童操作提示及工作報告，保留玩法條件與測試事實，沒有添加成效承諾。

| 原句／舊介面 | 原因 | 改成什麼 |
|---|---|---|
| 旅程時間、駕駛積分、個人最快紀錄 | 兒童課程聚焦照顧與抵達，避免數字競賽回饋 | 兒童結果隱藏時間和積分，改「這段風景記住了，再一起出發吧。」 |
| km/h、路段限速、m、00:00 | 成人儀表增加閱讀負擔 | 速度格與「停穩了」「快到站了」；兒童畫面隱藏單位與計時 |
| 新增路口操作說明 | 用短口訣對應當下行動 | 「停下看左右，等朋友都過完。」「路口空了，可以出發。」 |
| 新增車票操作說明 | 幼兒需知道先後關係 | 「看形狀和顏色，停穩再開門。」「朋友慢慢上車，等一等。」 |

新課程以圖示、短句與既有裝置語音服務同步提示，沒有新增錄音歌曲；「等等歌」以節奏口訣呈現。沒有本機可用音色時仍可完整看圖遊玩。技術數字、檔名與真實驗收結果不套用文案改寫。
