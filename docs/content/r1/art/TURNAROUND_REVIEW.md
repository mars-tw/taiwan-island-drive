# 路人身份與動作自審

VERIFIED／2026-10-18。image_gen.imagegen 第三次生成僅為文件區人物參考，不增加遊戲下載量。依 sprite-master 同一角色延伸正／側／背：行人藍衣橘褲藍黃鞋；單車黃帽珊瑚衣藍褲黃車；奶奶銀髮綠衫黃花裙與藍格菜籃車。九格頭部、腳部及主要道具可見；奶奶第一格為略三分之四正面，沒有把它說成嚴格正投影。阿路仍沿用既有 R7 三視圖。

運行使用的雙姿勢不是此參考表：sprite-master 中的行人左右腳交換、單車踩踏位置不同、奶奶前後腳交換。UI 交替兩張姿態並沿斑馬線移動，不稱完整骨架或高幀率走路循環。減少動態模式固定一個姿態與中央位置；流程仍等待朋友通過。

色彩用既有 R8 算法：alpha >128、Rec709 平均亮度、亮度<0.1視為近黑、HSV S<0.2視為低飽和。八個透明素材全部通過亮度0.30～0.75、近黑<35%、平均S≥0.32、低飽和<20%。數值見 color-gates.json；透明像素不參與計算。這是確定性量測與單一執行者自審，未進行3～8歲幼兒辨識或陌生玩家盲測。
