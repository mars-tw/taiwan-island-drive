## 八大面向

| 面向 | 本輪做／不做與理由 |
|---|---|
| 1 美術 | 做護照與星等的既有 UI 語言整合。無新增原畫；不以程序化素材冒充新美術。 |
| 2 按鈕 | 做兒童主操作 ≥60px、次要操作 ≥44px、完整邊界與遮擋測試。 |
| 3 選單 | 做護照分模式分頁、每頁 4 關、固定關閉／返回、不靠長捲動選關。 |
| 4 人物 | 不改模型：本作交通工具主角，新角色化模型列缺件。 |
| 5 地圖模型 | 使用既有主題地圖，增加可玩路線配置；不製作新模型。 |
| 6 技能 | 做兒童操作回饋、汽車自動油門與取消／暫停清除，關卡完成才給章。 |
| 7 角色樣子 | 不宣稱角色雙閘或三視圖通過：沒有新增模型，舊資產美術問題保留在缺件清單。 |
| 8 動作流暢度 | 保留真實載具輪轉與物理；減少動態偏好仍生效。沒有新人物動畫，不以單圖晃動冒充。 |

## 驗證邊界

- 效能只可標「並發載量測，僅供參考」，不宣稱通過出貨效能閘。
- 新 2D 美術若無可明確指定的 `gpt-image-2`，列缺件；本輪不需新美術即可完成玩法。
- 不加新音樂／音效素材，沿用既有回饋；未做 iOS／Android 實機與原生包驗證。
- 測試不得直接寫入完成旗標來冒充實際玩法；純邏輯測試可加速時間，但須經物理／任務完成條件。
