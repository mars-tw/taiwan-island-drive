# R47 優化清單（2026-11-02）

本輪依 `game-optimization-round` 流程，先跑基線（`npm test` 393 項全過、headless 截首頁、列車數學課、汽車、火車、飛機），再挑對 3～5 歲孩子最有感、風險最低的項目。這是已上架 App，學習內容、隱私行為（不連網、不蒐集資料）與兒童分級都不動。

## 基線看到的問題

1. Android 包內的 `ic_launcher` 系列還是舊的墨綠扁平圖示（飛機、火車、汽車），跟商店與 iOS 的石虎吉祥物不一致。Manifest 其實已指向 `ic_transport_v2`（石虎），舊圖是沒被選用、但仍打進包裡的殘檔。
2. 列車數學課第 2 站按「分好了」時，如果後車廂人數不對，畫面上什麼都沒變：提示文字被刻意隱藏，教練泡泡也照舊。孩子不知道為什麼沒前進，容易卡住。第 3 站選錯答案時，直式手機高度 700px 以下也會被隱藏。
3. 第 1 站裝人時，橘色「人數好了，去分車」一開始就最醒目，孩子第一眼會先按它，但人還沒坐滿，按了也只是在被藏起來的地方說「還需要幾人」。
4. 火車頁手機直式的「交通學院・火車課」標題與「路線／課程」按鈕會擠成兩行（外觀問題，不影響操作）。
5. 桌機首頁「開飛機」卡片的插圖用 `loading="lazy"`，開頁瞬間會晚一點才出現（外觀問題）。
