# R5 兒童文案校對

依核心規則mode 2直接執行；數學數量、流程、存檔與移植原教材不改。

| 原句 | 原因 | 改成什麼 |
|---|---|---|
| 每位朋友都有座位。一起數一數！ | 每站重複，沒有角色反應 | 裝滿：月台的朋友在等你，請他們上車吧！／分車：朋友換車廂，總人數一樣多。／算剩下：橘色車廂留下來，藍色車廂帶走幾人？／完成：你會合起來，也會分開算。綠旗出發！ |
| 再開一班，換個數量 → | 控制太長 | 再開一班 |
| 調度完成！一班列車，兩種算法 | 結算標題冗長，雙獎章已負責說明 | 調度完成！ |
| 按綠色按鈕，準備出發！ | 改版依流程亮黃，避免顏色指令矛盾 | 跟著亮起的按鈕，準備出發！ |
| 按綠色按鈕，開始前進！ | 同上 | 準備好了，按「開始前進」！ |
| 快到站了！按黃色「幫我停好」。 | 按鈕改短名稱 | 快到站了！按「停好接客」。 |
| 學生證 | 空條缺身份與紀錄 | 保留學生證入口，補阿路頭像與「小小學員・N星」實際紀錄 |

新增短標「合起來」「分開算」「留在海風站」對應實際數量與車廂狀態。沒有新增分數承諾、倒數壓力或外部連結。
