# R5 開源美術技法讀回

2026-10-16，延續R4研究，當次讀取官方GCompris screenshots及SuperTuxKart Style頁。

- https://www.gcompris.net/screenshots-en.html ：圖像入口先於文字閱讀。落地為三種同視角大車插畫、乘客可見身體與重複辨識配件；不複製其素材。
- https://supertuxkart.net/Style ：使用愉快且容易閱讀的世界、明確輪廓。落地為左上光、暖黃帽／橘背心與海藍遠景的冷暖分離、減少同時橘色CTA、不讓深色駕駛艙主導幼兒畫面。

本輪僅2D製圖與UI／既有3D視野調整，不新做模型；父層3D模型需Blender重工的規則不作為2D圖的虛構製程。十次實際圖片工具呼叫、原alpha與後製皆另有manifest。來源是技法參考，沒有新增第三方圖片或SDK。
