# 島嶼交通學院：陽光海岸交通繪本

2026-10-18，R8／送審前深度優化延續 R4～R7。以下舊輪規格保留作追溯；文末 R8 是現行覆寫。觀眾 3～8 歲；第一眼是跟教練一起搭車旅行，主工作是接下下一章任務。

## 識別與色票

記憶點為「海藍路牌＋橘白斜紋出發票＋黃帽綠旗石虎教練＋台灣路線」。世界是明亮台灣海岸、榕樹與綠山，玩具比例、圓潤輪廓、乾淨色面與柔和紙感；無深青整頁底、無米字深色卡片、無 emoji 主視覺。

## 字型與層級

不新增網路字型或外連。圓潤展示字用本機「微軟正黑體／PingFang TC」900 粗體、適當字距；數字沿用已內建 Barlow Condensed。Logo 使用生成字圖，DOM 保留完整無障礙名稱。標題 28～40px、章名 20～28px、按鈕 16～20px、正文 14～18px、輔助 12～14px。窄橫向可降輔助字，不縮兒童觸控目標。

## 造型語彙

厚 3px 海藍輪廓、22～28px 面板圓角、4px 深藍落地影；主要按鈕像厚塑膠路牌，橘色配短動詞；次要按鈕白底藍框。互動元件使用 8px 圓角，讓 60px 完整矩形的角落也可命中，沒有為造型放寬控制測試。面板使用生成的橘白交通斜紋邊材與白閱讀面。交通票帶虛線接縫，學生證像旅程集章票，完成與未完成有文字與形狀區分。

圖示統一圓潤繪本貼紙：粗墨藍輪廓、黃橘藍三主色、無字、64px 能辨認汽車／列車／飛機／星章／觀察號誌。圖示不是互動判定來源。

## 角色與場景

「阿路教練」鎖定黃帽、橘反光背心、藍吊帶褲、橘鞋、圓耳與斑點石虎臉。R5 改持綠色調度旗，有旗落／舉旗兩個真正不同手臂與表情姿勢。六位全身乘客以髮型、船帽、花夾、眼鏡與書包辨認，各兩張不同肢體步態；上車與跨車補間700ms並交替姿勢。不是骨架動畫，也不宣稱完整走路循環。左上45度暖光、墨藍輪廓在全批提示固定；人物在390寬主要階段至少48×76 CSS px。

首頁三車改成同視角同光源的繪本「選課插畫」，每種只一輛；進入遊戲後仍使用原Blender模型與即時物理。火車幼兒模式採明亮開闊前窗，移除深色駕駛艙遮擋；海岸天空為生成遠景，軌道、車輛、月台、號誌仍即時3D。家長模式保留可操作駕駛艙，儀表改中文紙白，不以背景畫冒充行車。

R5 奠定「阿路綠旗＋前藍後橘列車＋登車票」。裝滿畫面先看排隊，分車畫面突出加法牌，算剩下用問號翻牌與留站橘車，結算是雙獎章票。R6 列車駛出3秒，其餘揮旗／彩帶1.5～1.8秒，可立即按下一步離開；系統減少動態下不播放位移／步態／揮旗／翻牌。

桌機：橫幅主線＋三張登車票；手機直式：教練主線＋三張橫票；iPad：增加主線舞台；矮橫向：單行主線＋三票。火車直式三個主鈕與輔助列、橫式視野與右側操作台並排；既有六個控制均保留且至少60px，依流程只突出下一步。首頁唯一橘色主線鈕，三車入口改白底藍框。手機不出現鍵盤說明。
