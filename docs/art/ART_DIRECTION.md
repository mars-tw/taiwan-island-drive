# 島嶼交通學院：陽光海岸交通繪本

2026-10-16，R4。觀眾 3～8 歲；第一眼是跟教練一起搭車旅行，主工作是接下下一章任務。

## 識別與色票

記憶點為「海藍路牌＋橘白斜紋出發票＋戴黃帽的石虎教練」。世界是明亮台灣海岸、榕樹與綠山，玩具比例、圓潤輪廓、乾淨色面與柔和紙感；無深青整頁底、無米字深色卡片、無 emoji 主視覺。

| 色 | HEX | 使用 |
|---|---|---|
| 海藍 | #1479B8 | 外框、標題、導覽 |
| 墨藍 | #143B61 | 正文、輪廓、高對比 |
| 出發橘 | #F46B27 | 主操作，配墨藍字或白字依對比 |
| 號誌黃 | #FFD344 | 徽章／重點，只作點綴 |
| 草地綠 | #58B85B | 背景植栽與已完成紀錄 |
| 雲白 | #FFFFFF | 面板、文字閱讀面 |

暖冷對比集中在出發鈕與教練黃帽。背景避免太多白面積，角色深輪廓保持但近黑比例 <35%；人物可見像素平均亮度 0.30～0.75、平均 HSV 飽和 ≥0.32、低飽和 <20%。透明區不計入人物閘。

## 字型與層級

不新增網路字型或外連。圓潤展示字用本機「微軟正黑體／PingFang TC」900 粗體、適當字距；數字沿用已內建 Barlow Condensed。Logo 使用生成字圖，DOM 保留完整無障礙名稱。標題 28～40px、章名 20～28px、按鈕 16～20px、正文 14～18px、輔助 12～14px。窄橫向可降輔助字，不縮兒童觸控目標。

## 造型語彙

厚 3px 海藍輪廓、22～28px 面板圓角、4px 深藍落地影；主要按鈕像厚塑膠路牌，橘色配短動詞；次要按鈕白底藍框。互動元件使用 8px 圓角，讓 60px 完整矩形的角落也可命中，沒有為造型放寬控制測試。面板使用生成的橘白交通斜紋邊材與白閱讀面。交通票帶虛線接縫，學生證像旅程集章票，完成與未完成有文字與形狀區分。

圖示統一圓潤繪本貼紙：粗墨藍輪廓、黃橘藍三主色、無字、64px 能辨認汽車／列車／飛機／星章／觀察號誌。圖示不是互動判定來源。

## 角色與場景

「阿路教練」是親切的台灣石虎交通教練：黃帽、橘背心、藍工作服、圓耳、臉頰斑點、白口鼻、可辨認眼眉，手持圓形停看牌。六位乘客以暖棕髮、帽子／髮夾／眼鏡與同色系書包辨認，佔用座位顯示生成的小臉；空位是教材座格。角色都是靜態圖，不描述成會說話或行走的角色動畫。3D 車輛保留真實原模型與預覽；生成交通插畫是按鈕貼紙，不假冒模型。

桌機：橫幅主線＋三張登車票；手機直式：教練主線＋三張橫票；iPad：增加主線舞台、避免棚拍圖被拉長；矮橫向：單行主線＋三票，功能全可達。所有兒童操作至少 60px，手機不出現鍵盤說明。安全／數學／學生證與三模式沿用同組框色與圖示。

## 同帳號區隔

其他 repo 只讀目錄／既有規則與樣式，沒有寫入：末日、塔防／攻城、裂潮卡牌以深色戰鬥／卡框為主；農場保留像素語言；七期用 3D 劇情；Crackveil 不動。本作使用日間海岸、幼兒繪本角色、交通路牌與登車票；不共用戰鬥 HUD、卡牌外框或像素質感。若其他線路同時變更，這是當次唯讀邊界，不保證其最後設計。

## 開源美術研究與落地

- [GCompris 官方畫面與操作](https://www.gcompris.net/screenshots-en.html)：圖像入口與固定工具列讓兒童辨認活動。借鏡「圖像＋短標籤」與固定返回；不複製素材。
- [SuperTuxKart 風格指南](https://supertuxkart.net/Style)：兒童友善需明確愉快與可閱讀的空間。應用到高亮海岸、教練表情及避免陰暗棚拍主導。
- [SuperTuxKart 模型指南](https://supertuxkart.net/3D_Model_Guidelines)：保留物件可認形態、簡化細節並統一風格。應用到64px交通圖示，保留車輪／翼／列車前窗；不以方塊替代既有車。
