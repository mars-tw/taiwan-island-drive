# R49 美術研究：小朋友看得懂的遊戲卡片圖示

日期：2026-11-24。目的：數學遊戲室 23 張遊戲卡、4 個分頁的圖示，現在是 ●、◆、⌁、🔀 之類的符號，3～8 歲小朋友看不出在玩什麼。先讀開源專案怎麼做圖示，再寫成本輪的提示詞規則和驗收方法。

## 寫成規則（用在提示詞）

1. **一張一個動作或一個物件**：卡片只有 56px，圖示的工作是讓小朋友認出「在玩什麼」，不是畫出完整玩法。主角之外最多兩個小配角，不畫整個場景、不畫樹和雲。
2. **剪影先過關**：主角外輪廓要能單獨認出來（車廂、時鐘、天平、放大鏡、Y 形軌道）。墨藍粗外框（1024px 原圖約 16～20px），裡面的線不細於 8px。
3. **少色、平塗、兩階明暗**：學院海藍、號誌黃、出發橘、草地綠加白，每張最多五色；左上暖光，只分亮面和一階暗面。
4. **依分頁分底色**（MUSE 建議，本輪採用）：數學淺奶油黃 `#FFF3C2`、觀察與記憶淺薄荷綠 `#DCF2DF`、拼搭與方向淺天藍 `#D9EEFA`、生活與分享淺蜜桃 `#FFE7D3`。不識字的小朋友可以靠底色記房間，但圖案本身仍要分得開。
5. **安全圓**：主體整個放在中央直徑約 70% 的圓裡，四角和外圈只留底色，CSS 裁成圓形時不會切到東西，也就不用去背。
6. **不放字**：只有「排車廂」放 1、2、3（數字就是玩法）；數學分頁原本也畫 123，盲測跟排車廂撞，最後改用大加號配小減號、小等號；時鐘只畫刻度點，數數看、上下車不放數字，避免洩漏答案。
7. **同題材拉開**：上車下車＝車門特寫＋進出箭頭；海風站上下車＝海鷗、海浪、整節車廂、不畫箭頭。拆合調度台＝側面車隊、拆開一節；調車場＝俯視三條側線。比一比＝兩疊車票；貨運天平＝只畫天平。
8. **俯視列車**（直式轉轍器）：嚴格從正上方看，車頭做圓弧鼻子＋白色擋風玻璃、車尾平切；車身只用一種藍，車上不要黃橘綠紅，因為遊戲用色相旋轉把藍車變綠、紫、紅車，雜色一轉就亂了。

## 寫成驗收（用在挑圖）

1. **64px 總覽圖**：每張縮到 64px 排成總覽，另做一份 56px 圓形裁切版，給 MUSE 看，每張要說得出是什麼遊戲；認不出來或兩張被說成同一件事的，重畫主角，不用加細節補救。
2. **灰階看一次**：轉灰階後主體跟底色仍分得開（Sugar 的「不能只靠顏色」）。
3. **安全圓檢查**：用程式量圓外的像素是否都接近底色，超出的重畫或重新置中縮放。
4. **檔案**：WebP，單張最好 ≤ 40KB。
5. **俯視列車**：去背後檢查四角 alpha＝0、邊緣沒有洋紅色殘邊，並預覽綠、紫、紅三種色相旋轉，車頭方向仍看得出來。
