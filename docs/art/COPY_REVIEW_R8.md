# R8 繁中文案 mode 2 事後紀錄

這次修改七組對外文字。套用 speak-human-tw，依核心規則常駐mode2直接修改，不另問確認。保留品牌、星數、人數、存檔與課程規則。

| 原句 | 原因 | 改成什麼 |
|---|---|---|
| 慢慢開（任何速度） | 五格全亮仍稱慢，語意錯誤 | 停穩了／慢慢開／前進中／開得快，依實際速度 |
| 飛行中 · 高度144公尺 ·129公里／時 | 成人儀表數字缺乏視覺參照 | 離地飛行＋離地高度格＋前進速度格 |
| 人數好了，去分車 → | 滿員時下一步不明顯 | 坐好了，去分車 → |
| 4＋1＝5（乘客還在走） | 算式比畫面提早完成 | 朋友正在上車／換車廂…；入座後才顯示算式 |
| 找到一顆星星！ | 消失後不知道目標進度 | 原鼓勵保留，另常駐找到X／總數 |
| 月台的朋友在等你，請他們上車吧！ | 滿員後仍叫孩子上車 | 滿員時改為「朋友坐好了！按橘色車票去分車。」 |
| 副駕阿路舉起剛找到的星星 | 新安全小窗是靜態插畫，不能描述不存在的手勢 | 阿路教練坐在閉合車窗內，繫好安全帶；再加當前路況／得星短句 |
