# 飛行視窗與幼兒介面

2026 年 10 月 6 日，2.2 版。

對象是 3～5 歲孩子與陪玩的家長。畫面的工作是看清飛機、知道下一個動作，並用單次點擊操控。

介面沿用飛機儀表的深藍，固定色票為深藍 `#143B4F`、面板 `#1F4759`、天空 `#A1D6E1`、起飛按鈕 `#F2C67B`、助飛提示 `#6DA69B`、說明列 `#E8F1F0`。中文操作用正黑體與 Noto Sans TC，數值使用 Barlow Condensed。代表性構圖是獨立的飛行視窗：上方只有任務標題與短提示，下方是有實體高度的控制列。

```text
交通學院導覽
旅程名稱　返航／視角／聲音／暫停
一句下一步提示與進度
┌────────────────────┐
│  WebGL 飛行視窗       │
│  完整飛機與前方地景    │
└────────────────────┘
高度／速度　　　看儀表
向左　　　主動作　　　向右
```

`#flight-window` 取得真正可用的長方形，`#flight-stage` 與 WebGL canvas 對齊這個區域。ResizeObserver 與螢幕旋轉會重新量測；控制列及任務列位於 canvas 外。直向的儀表展開時同步縮小視窗；短橫向使用右側控制列，列內可捲動，維持完整飛行區域。隱藏的儀表不呼叫 Canvas 2D arc，避免半徑為負值。

幼兒只顯示三顆大按鈕。左右使用 click 設定目標航向，主動作呼叫持續助飛；不需要按住或反覆調油門。返航使用飛行控制器的物理航線，可取消。家長模式保留操縱桿、油門、襟翼、煞車與方向舵，放在控制列中。

選單優先顯示尋寶、郵差與巡航，起飛、導航、降落與自由飛行仍可選。家長設定收合，孩子選旅程後按一次出發，就會開始相應的助飛流程。
