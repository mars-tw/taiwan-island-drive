# 幼兒飛行控制與玩法升級

2026-10-06。只改飛行控制、玩法、任務資料與測試；原有 `physics.js` 的升力、阻力、迎角失速、推力、重力、輪胎接觸及煞車模型維持。

## 幼兒怎麼操作

選好玩法後只要點一次出發，助飛會持續準備、推油門、到起飛速度時輕拉桿、爬升與管理巡航油門。所有階段都輸出有限的油門及舵面操作，逐步交給原物理積分，不修改飛機位置、速度或直接取得分數。

左右按鈕改為單次點擊，目標航向每次約 25°，相對當下航向最多 40°。地面轉彎先排隊，實際加速時保持跑道中線；離地後才轉彎。任務飛行短暫轉向約四秒，再接回路線；同方向連點不會不斷疊加轉向。自由飛行會保持新航向並自動回平機翼。

降落也是單次動作，助飛逐步調整下降率，接地後用輪胎煞車停好，不需要一直按住。返航依序飛過機場外圍、底邊及進場航點，對準跑道後降落、煞停；再點中央按鈕可取消返航。返航不重設位置或速度，重複點返航也不會把航線重頭開始。

助飛及自動返航期間使用原物理模型的穩定回復力矩，`effectiveAssist` 會顯示實際狀態。家長手動模式保留原鍵盤、操縱桿、襟翼、油門與煞車；取消返航後恢復原手動偏好。

## 新玩法

| 玩法 | 完成條件 | 物理試跑 |
| --- | --- | --- |
| 空中尋寶 `treasure` | 真正飛近六顆星星，依序取得寶藏。 | 第一份回饋約 8～12 秒，全程約 62 秒。 |
| 飛行郵差 `mail` | 在適當高度及航跡釋放郵件，郵件繼承飛機速度、受重力落地，落在送達區才算完成。 | 兩份郵件約 52 秒。 |
| 島嶼巡航 `tour` | 飛近三個原創景點，保持平穩並在觀景區至少三秒。 | 三個景點約 219 秒。 |

新玩法從既有空中練習狀態開始，避免每次都先等完整起飛；只有開始新局、重來或回選單時設定起始狀態，活動進行中沒有瞬移。原起飛、導航、降落及自由飛行仍保留；單次幼兒起飛約 39 秒，降落含煞停約 55 秒。實際時間會隨機型、轉向與操作改變。

四個場景為 `coast`、`valley`、`island`、`metro`，可探索範圍 36×36 km、公尺 SI，X／Z 各為 −18,000～18,000。巡航景點到約 9 km，自由飛行不再受舊的 5 km 邊界限制。景點與山海是台灣題材的原創縮尺地景，沒有宣稱測繪或精確地理重現。

## 提供給 UI 與場景的 API

```js
game.childControl();     // 單次開始並持續助飛；返航中按下可取消
game.childTurn(-1);      // 單次向左
game.childTurn(+1);      // 單次向右
game.returnHome();       // 實際飛行返場及煞停，重複呼叫不重開航線
game.dropMail();         // 家長模式可用 P 提出投遞要求
const state = game.getState();
```

- `state.pilot`：`active`、`stage`、`targetHeading`（弧度）、`targetAltitude`（公尺）、`turnRemaining`、`returning`、`returnIndex`、`returnRoute`、`terrainClearance`。
- `state.mission`：保留 `mode`、`phase`、`passed`、`complete`、`retry`、`score`；新增 `total`、`progress`（0～1）、`stage`、`target`、`targetLabel`、`targetDistance`（公尺）。
- `mission.targets`：`{ id, label, kind, x, y, z, radius, visited }`；郵件目標另有 `flightAltitude`，景點另有 `dwellSeconds`。返航中對外呈現四個返航航點，原玩法資料仍保存，取消後繼續原玩法。
- `mission.activeParcel`：`{ id, targetId, position, velocity, age }`，方便繪製真正在落下的郵件。
- `mission.events`：最多保留八筆 `{ id, type, label, time }`；`eventSequence` 持續增加，超過八筆不會重複 ID。種類包括 `star`、`ring`、`landmark`、`mail-drop`、`mail`、`mail-missed`。
- `getFlightTargets(mode, map)`：場景可從 `flight-plans.js` 讀取同一份航點。

若場景提供 `world.terrainHeight(x,z)`，助飛會讀取前方 600／1,200／2,200 m 的地形，透過舵面及油門嘗試保持高度餘裕；在機場進場階段降低餘裕，讓飛機能實際下降。這項處理不直接把飛機抬到地形上方。

## 驗證與限制

本次 `npm test` 共 **76 項全部通過**，其中飛行 40 項；原全專案 60 項保留，僅把舊的兩次操作提示驗證更新為單次助飛提示。新增單次起飛、地面連點保護、正確左右方向、放手接回任務、三玩法×四場景×兩機型完整通關、早期回饋、郵件重力落地、景點停留、物理返航、取消無瞬移、事件 ID、36 km 範圍與可重現性。

目前返航會使用寬轉彎與正式進場路線。距離較遠時需要飛行時間，並非立即回到機場；由原導航起點試跑約 316 秒。幼兒短任務則維持五分鐘內可完成。

地形防護是有限助飛，不是完整障礙物碰撞或航空認證的地形告警系統。航路規劃使用原創安全走廊；場景高樓、山海視覺與手機／平板 UI 的最終驗收由整合流程處理。本文不把確定性測試當作裝置實測。
