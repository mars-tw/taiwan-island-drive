1. 傾斜與修正分開：左右倒、錯向、放開、按對、95%、100%、煞停／休息完成原尺寸圖；可出發時必為100%，無紅箭頭。
2. 延後正解：三課各有未提示與錯後提示圖；首次輸入前無正解標記；安全禁用獨立維持。
3. 三路口四狀態：接近、通過、離場、淨空；未淨空提前出發不移車、不移行人，顯示停住原因；另有三站牽車start／middle／pavement。
4. 三站決策／錯選／選對，以及同人候車→走向月台→登階→進門→走道→坐下六格；姓名保持，坐下才加1，暫停不跳格。精選最多15張，採每課5張，其餘保留完整證據並如實說明精選容量限制。
