2. 路口場景真的看左／看右：駕駛位置發出的觀察範圍與目標來車同時改變；統一完成態按鈕短句。三站路面方向、來車方向與人物起點至少兩項不同。驗收字幕以外也能辨識側向、過街人物與停止線，三站九次重新觀察、到岸才計數；固定場景及四鍵尺寸，狀態切換不跳動。
3. 車票由玩家選月台：未選三牌同等；同站錯選指出形狀或顏色，改選後自行前進、停穩才開門。上車改為先選人物、再確認邀請。驗收未選→錯選→正確開門三格；另有邀請→跨門檻→入座、手動收階→關門→駛離。放大窗正式圓角、當前動作標題，保留同人物定位。站名與人數分列，名牌在腳下；三站、320×568／390×844／568×320自動檢查不重疊、不截字。
4. 三課專屬結尾圖像回顧：完整蛋糕與分享、同三位朋友在對岸道謝、列車帶同三位乘客到海邊。成果短句對應實際行為，不把跨站人次寫成九位不同角色。驗收三課完成並重載讀回，主畫面能辨課。
