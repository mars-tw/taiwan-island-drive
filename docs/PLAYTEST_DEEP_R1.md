# 深度試玩第一輪

最影響留存的三項已實作：

1. **動作與教材不同步／連點跳步。** 乘客700ms移動期間顯示「朋友正在上車／換車廂…」，暫停下一步與移車；入座才恢復正確算式與按鈕。每次增減／移車使用既有tap音效，滿員時明示橘色下一步；保留3歲孩子按鈕操作與減少動態模式。
2. **自動油門太急，速度格意思不清。** 幼兒自動巡航改以65公里／時附近調節油門，保留手動油門與煞車。速度格只依實際速度；停穩、慢慢開、前進中、開得快各有適用範圍，不再收星就誤稱慢速。沒有增加新經濟或獎勵數值。
3. **飛行狀態與目標讀不懂。** 真離地高度改格數，地面／飛行清楚分開；新天空航線、平塗黃機與上方金星使空中狀態可讀，常駐「找到X／6」延續鼓勵。儀表只留家長可展開入口；自然得星事件與獎勵數量未變。

重新驗收見 `docs/evidence/deep-r1/acceptance-r8.json`：真實起飛、自然碰撞得星、分車完成後前4後1、動畫中禁連點、幼兒自動巡航、固定暫停位置；沒有用修改完成旗標拍商店圖。
