## 說明

海風站的朋友要去山海教室，第一份調度單交給你！
把乘客裝滿列車、移到另一節車廂，再數數前車帶走幾人。
接著開火車停站接朋友、開車沿海岸送補給，最後起飛找路標。

【一趟山海同行】
四個章節依序交接。數學課的調度結果會帶到火車課；完成接客才繼續公路，再去空中找星星路標。學生證、收集星星和徽章都在同一款遊戲裡。

【動手拆合，不怕答錯】
每個圓點代表一位乘客。一次上車或移動一人，移錯可搬回來，答錯能再數一次；沒有倒數，也不扣分。幼兒模式用小數量，家長可選較完整操作。

【保留熟悉的交通課】
原有汽車、火車、飛機自由操作、12 關旅程與三站安全觀察課繼續保留。練習鬆油門、煞車、停穩開門、等待號誌與飛行助控。這是親子遊戲，不能取代真實駕駛或飛行訓練。

【留在這台裝置】
主線與課程進度本機保存。升級保留舊星星與護照；家長可選擇匯入《小小列車長》的 JSON 備份，接續拆合進度。未移植玩法只保留歷史原文，無法直接接續當次拼圖或其他旅程。

【免費，沒有廣告】
不需帳號，沒有內購、評分請求、廣告或第三方分析 SDK，App 內沒有外連。家長設定與匯入需先通過家長關卡。原生版素材隨 App 安裝，可離線玩；網站版首次完整載入快取後可離線。觸控主操作至少 60 CSS px，支援手機直橫與平板。

開源程式依 MIT／Apache-2.0 與素材各自授權提供。歡迎親子一起探索，也歡迎開發者在授權條件下做出自己的遊戲。

## 此版本新增內容

- 新增「山海同行」四章主線：列車數學→停站接客→公路補給→空中找路。
- 《小小列車長》的拆合玩法加入學院，沒有另外安裝或跳到另一款遊戲。
- 新學生證統整主線、星星、原 12 關與觀察章，升級保留舊進度。
- 家長可選匯入舊數學備份；錯誤備份不覆蓋現有進度。
- 調整窄螢幕的入口、學生證與章節交接按鈕。
